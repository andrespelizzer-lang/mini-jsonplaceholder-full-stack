# Mini JSONPlaceholder

Educational monorepo — a simplified Italian version of JSONPlaceholder for teaching backend/REST API concepts to students.

## Current migration

**The `web/` folder is being migrated from plain HTML/CSS/JS to Nuxt 3 (Vue.js framework).** The backend (`api/`) stays unchanged.

## Stack

- **Runtime:** Node.js (ES Modules)
- **Backend:** Express 4 (in `api/`) — NOT changing
- **Frontend:** Migrating from plain HTML/CSS/vanilla JS to Nuxt 3 (in `web/`)
- **Database:** MySQL 8 via Docker
- **DB driver:** mysql2/promise (raw SQL, no ORM)
- **Package manager:** npm

## API endpoints (backend — unchanged)

### Utenti (`/api/utenti`)

- Fields: `id`, `nome`, `email`, `citta`, `codiceFiscale`, `sesso`, `dataNascita`, `telefono`, `password`, `ruolo`
- GET, POST, PUT, PATCH, DELETE — full CRUD
- Auth: JWT with bcrypt passwords, role-based (utente/admin)

### Post (`/api/post`)

- Fields: `id`, `userId`, `titolo`, `corpo`
- GET supports pagination: `?page=1&limit=5` — returns `{ dati, totale }`
- Full CRUD with ownership check (author or admin)

### Commenti (`/api/commenti`)

- Fields: `id`, `postId`, `nome`, `email`, `corpo`
- Full CRUD

### Auth (`/api/auth`)

- POST `/registrazione` — creates user with hashed password
- POST `/login` — returns accessToken + refreshToken
- POST `/refresh` — returns new accessToken
- POST `/logout` — deletes refreshToken from DB

## Conventions

- Error responses use `{ "errore": "..." }` (Italian)
- Successful DELETE returns `{ "messaggio": "... eliminato", "<risorsa>": { ... } }`
- POST returns `201`; validation errors return `400`; not found returns `404`; DB errors return `500`
- IDs are auto-generated by MySQL (AUTO_INCREMENT)
- Foreign keys: `post.userId -> utenti.id`, `commenti.postId -> post.id` (both ON DELETE CASCADE)
- DB credentials live in `api/.env` (gitignored), template in `api/.env.example`
- CORS is enabled in `api/server.js` via the `cors` npm package
